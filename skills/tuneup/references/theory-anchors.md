## 0. 增长协议（先读这个再动笔）

锚词典的价值随条目数和核实质量复利增长，但**只增不核会把词典变成迷信集**。两条增长线，各有闸门：

**A. 正面锚入册（新理论锚 / 新黑话翻译 / 高价值人名锚组合）——三闸全过才入：**
1. **可溯源**：提出者 + 年份 + 原始文献/著作查得到一手源。查不实年份/归属 → 只写理论名入册，年份栏留空（宁缺毋错）
2. **证据现状**：主动查一遍"这理论被复制危机波及了吗 / 有没有元分析翻案"——查出问题直接改投黑名单，这条比入正面表更值钱
3. **强度标注**：标明是**机制同构**还是**强类比**——类比锚使用时措辞降级（"借用 X 的视角"而非"依据 X"）

**B. 黑名单增长（发现新证伪 / 新滥用模式）——两要素才入：**
1. 反证可溯源（元分析 / 系统综述 / 提出者本人澄清）
2. 给出替代锚（只拆不立的黑名单没人用）

**喂养回路**（谁来让它增长）：
- 任何会话中挖到新锚、核出新伪 → 顺手 append 本文件 + 提交
- 周期性学习/进化循环（日课、领域研究 loop）挖出的理论锚 → 沉淀入册，而不是只留在当日笔记里
- 外部贡献走 PR，维护者按同一套闸门审

**条目格式**：`| 锚名（提出者 年份） | 一句话说明它锚什么 | 同构/类比 | 入册日期 |`——入册日期让"哪些是新增长的"可追溯。

## 1. 什么是理论锚

概念锚点的第三类（前两类见主 SKILL.md：抽象锚 / 人名锚）：**具体理论名 + 提出者 + 年份**。

- 理论名在 LLM 权重空间是高密度锚点——一个词唤起整张语义网络。「这个界面的 **signifier** 够不够」≫「用户能看出来能点吗」；「按 **ZPD** 设计学习曲线」≫「难度别跳太快」；「用 **Pre-mortem** 检查方案」≫「想想可能出什么问题」。
- 用模糊白话 = 让 AI 猜你要用哪套框架；用对理论名 = 把一个学派几十年的研究一次性接进对话。
- 三类锚可叠加，强度递进：抽象锚（"第一性原理"）< 理论锚（"前景理论 Kahneman & Tversky 1979"）< 理论锚 + 人名锚组合（"像 Norman 那样审视这个交互的 signifier"）。

## 2. 怎么挖到新锚（三层挖掘法）

别问「这活儿在岗位上怎么做」，问：**此刻用户/读者/玩家的大脑在干什么，我在利用（或违反）哪条认知规律？**

1. 把任务还原成能力（"让玩家不看地图也知道往哪走"，而不是"关卡设计"）
2. 问这个能力底下是哪门学科研究了几十年（查速查表，或直接问"这个效应的学术名字叫什么"）
3. 把理论名（带年份）写进 prompt——**并按 §0 增长协议入册**，让下一次不用重新挖

## 3. 黑话 → 学术名翻译表（急诊车道用 · 可增长）

用户说不清、只会用行业黑话/模糊白话时，先翻译再锻造：

| 用户的模糊表达 | 翻译成理论锚 | 入册 |
|---|---|---|
| 辨识度 / 剪影 | 格式塔组织律 · 图底分离（Wertheimer 1923） | 种子 |
| 打击感 / 重量感 | 因果知觉·发射效应（Michotte 1946） | 种子 |
| 留白 / 呼吸感 / 气口 | 负空间知觉与图底反转；认知负荷短暂释放；事件边界 | 种子 |
| 节奏 / 太赶了 / 拖了 | 事件分割理论（Zacks 等 2007）：节奏 = 知觉边界密度 | 种子 |
| 钩子 / 卖关子 | 信息缺口 Information Gap（Loewenstein 1994） | 种子 |
| 上头 / 看完还想看 | 峰终定律（Fredrickson & Kahneman 1993）+ 信息缺口闭环 + 准社会关系 | 种子 |
| 氛围 / 温度 | 色彩-唤醒-情绪映射；前景-庇护理论（Appleton 1975） | 种子 |
| 品味 / 手感 / 够好了 | 专家组块知觉（Chase & Simon 1973）+ 满意化（Simon 1956） | 种子 |
| 生命感 | 生物运动感知（Johansson 1973）；animacy 意图归因 | 种子 |
| 口号 / slogan / 金句不响不好记 | SUCCESs 六项黏性检验（Heath 兄弟 2007）+ 超级话语口语化（华与华）+ own-a-word（定位理论）——详见 §6 品牌/口号组 | 2026-08-02 |

**急诊车道病因「白话稀释」**：用户其实有精确的框架需求，但用黑话/白话表达 → AI 只能猜他要哪套框架。修法 = 按此表（或三层挖掘法）翻译成理论锚再重写。翻译不到的 → 挖出来 → 入册。

## 4. 🚫 误用理论黑名单（锚点核伪 — 注入前必查 · 可增长）

**盲信一个权威名字，和盲信一个 AI 输出，是同一个认识论错误。**以下理论被行业天天引用但证据薄弱/已证伪/常被误读——别当锚注入，或注入时带修正措辞：

| 别这么用 | 事实 | 替代 | 入册 |
|---|---|---|---|
| 蔡加尼克效应（未完成任务更好记） | 2025 元分析排除原始研究后无记忆优势 | 信息缺口理论；Ovsiankina 效应（倾向恢复被打断任务） | 种子 |
| 心流 =「挑战=技能」斜线 / 50% 胜率 | 元分析仅中等关联；清晰目标与控制感同为前因 | 引 Flow 不绑斜线和胜率数字 | 种子 |
| Miller 7±2 → 菜单最多 7 项 | 现代实证约 4 chunks（Cowan 2001），且随知识变化 | 视觉搜索 + 熟练度测试 | 种子 |
| Affordance = 看起来像按钮 | Gibson 的 affordance 是行动者-环境关系，可见与否都存在 | 要说的其实是 signifier（Norman 2008 亲自澄清） | 种子 |
| 损失厌恶 = 痛苦是快乐的 2 倍 | 倍数高度依赖任务/金额/参照点/人群；存在大量 loss-tolerant 个体 | 引损失厌恶不绑倍数 | 种子 |
| Hick 定律 → 选项越少越好 | 原范式限于有明确刺激-反应映射的选择反应时 | 不证明把功能藏深会更快 | 种子 |
| Brooks 定律 → 任何时候加人都更慢 | 只针对已延期项目；Brooks 本人称"极度简化" | 限定条件后再引 | 种子 |
| 学习风格（视觉型/听觉型） | 按偏好配教学媒介能提高学习——系统综述无合格证据 | 认知负荷理论；双重编码 | 种子 |
| Dale 学习金字塔 10%/20%/90% | 伪造谱系，Dale 1946 原文无这些百分比 | 检索练习 / 测试效应 | 种子 |
| 孙子「知己知彼，百战百胜」 | 《谋攻篇》原文是**百战不殆**；Giles 译 "you need not fear the result of a hundred battles"（Gutenberg #132 全文实读）。不殆=风险下界，百胜=收益上界 | 引原句谈风险时用"不殆"语义；要谈必胜另找锚，别拿孙子背书 | 2026-08-09 |
| Clausewitz 摩擦 → 找到关键点加一道门 | 原文（On War I.VII）明说摩擦 "is not concentrated, as in mechanics, at a few points"，是弥散的、来自每一个体 | 弥散摩擦改信息流结构/准入规则；单点门只适用于集中式摩擦 | 2026-08-09 |

## 5. 锚点核伪自检（Phase 4 内部跑，不输出）

1. 注入的理论锚在黑名单里吗？在 → 换替代或加修正措辞
2. 归属 + 年份可信吗？**宁可只写理论名不写年份，也不写像模像样的错年份**——实测一批 51 条理论引用独立核实核出 10 条错，且没有一条"看起来有问题"，全部通顺、自信、像模像样
3. 理论锚是机制同构还是强类比？强类比 → 措辞降级（"借用 X 的视角"而非"依据 X"）

### 项目管理 / 交付节奏（立项 · 排期 · 跟进 · 裁决）

| 锚名（提出者 年份） | 一句话说明它锚什么 | 同构/类比 | 入册 |
|---|---|---|---|
| 管理杠杆率（Andy Grove《High Output Management》1983） | 管理者产出 = 其影响的组织总产出；按杠杆率选管理动作——一次设定长期生效的机制 ≫ 逐件人肉催办 | 类比（实战方法论） | 2026-08-02 |
| Cynefin 框架（Snowden & Boone，HBR 2007） | 先判问题域再选管法：Clear/Complicated 可估可排；Complex 只能时间盒探针；Chaotic 先止血。防「用执行型管法管探索型任务」 | 类比（sense-making 框架） | 2026-08-02 |
| appetite / 胃口（Ryan Singer《Shape Up》2019） | 立项给「值得花多少」的预算，不做「要花多久」的估时；胃口同时是断路器阈值（circuit breaker：超胃口断路重议，不自动续期） | 类比（实战方法论） | 2026-08-02 |
| Little 定律（John Little 1961） | 排队论定理 L=λW：吞吐不变时 WIP 越多单件周期越长——「owner 并行项目数」是可推导的硬红线，新项目上桌先问挤掉谁 | 同构（数学定理，应用于工作流为直接推论） | 2026-08-02 |
| Cost of Delay / CD3（Don Reinertsen《The Principles of Product Development Flow》2009） | 用「延迟成本 ÷ 时长」排序（加权最短作业优先）；把排期争论从嗓门赛变成经济账；发行窗口/平台活动=高 CoD | 同构（排序最优性有调度理论基础）/ 应用层实战方法论 | 2026-08-02 |
| 约束理论 TOC（Goldratt《The Goal》1984） | 系统吞吐由瓶颈决定：给瓶颈排产、非瓶颈服从瓶颈；Agent-native 团队的瓶颈几乎总是人类决策带宽与人肉在场位点，不是机器算力 | 类比（实战方法论，源自约束优化直觉） | 2026-08-02 |
| Goodhart 定律（Goodhart 1975；流行表述出自 Strathern） | 指标成为目标即腐化——机器信号（commit 数/登记频率）只可用于触发对话，不可用于考核排名，否则信号本身被刷废 | 类比（强经验规律，激励文献大量佐证） | 2026-08-02 |
| Kill criteria（Annie Duke《Quit》2022） | 裁决标准立项时前置：写明什么信号 → 继续/暂停/关闭；避免沉没成本让「僵而不死」项目吃掉带宽 | 类比（行为决策实战方法论） | 2026-08-02 |

### 叙事 / 人物（剧情文案 · 世界观 · 游戏叙事）

| 锚名（提出者 年份） | 一句话说明它锚什么 | 同构/类比 | 入册 |
|---|---|---|---|
| 救猫咪 beat sheet（Blake Snyder《Save the Cat!》2005） | 15 节拍表 + 「救猫咪时刻」：角色登场必须**在做一件事**、用一个具体动作赢得共情，禁自我介绍式出场；游戏侧适用于英雄登场台词/开场演出 | 类比（实战方法论） | 2026-08-08 |
| 人物编配 Orchestration（Lajos Egri《The Art of Dramatic Writing》1946） | 冲突不是撞出来的，是把互相反对的人物**刻意编配**出来的；群像=三角张力不是三条平行线；前提（premise）驱动一切人物选择 | 类比（实战方法论） | 2026-08-08 |
| 人物网 Character Web + 道德论证（John Truby《The Anatomy of Story》2007） | 所有主要角色是对同一个中心道德问题的**不同回答**；对手的功能=攻击主角的内在弱点；多主角/多职业设计=一题多答 | 类比（实战方法论） | 2026-08-08 |
| 主控思想 Controlling Idea（Robert McKee《Story》1997） | 一句话=价值+原因：故事证明什么价值经由什么因果胜出；世界观的双结局/阵营立场都应是主控思想的变奏 | 类比（实战方法论） | 2026-08-08 |
| Want vs Need + 幽灵 Ghost（编剧通用框架，Truby/Weiland 系统化） | 外在目标（want）与内在缺口（need）分离才有弧线；幽灵=入场前未愈合的旧事，驱动 need；台词与结局立场须与 need 因果一致 | 类比（实战方法论） | 2026-08-08 |
| Resonance / 共鸣设计（Mark Rosewater，MTG 设计专栏） | 风味的力量来自调用玩家**已有的文化母体**（top-down design：从文化原型出发设计机制与风味）；卡牌风味文本不另起炉灶，接住既有共鸣 | 类比（实战方法论） | 2026-08-08 |
| 角色 > 情节（Tom Abernathy & Richard Rouse III，GDC） | "Plot is overrated"——玩家离场记住的是角色与时刻，不是情节结构；文案预算优先砸角色功能与可复述时刻 | 类比（业界实证谈，GDC 调研支撑） | 2026-08-08 |
| 冰山理论 / 省略法（Hemingway《Death in the Afternoon》1932） | 冰山移动之庄严因八分之一在水上：写出的一分之下压着知道但不写的七分——省略的前提是作者知道，不知道而省略只留下空洞；世界观/场景设定用作「水下层登记」的锚（设定集登记水下七分，正文只露一分）。游戏侧更深一档变体=「永不写死」：连作者都不落答案的谜面（如《棋门遁甲》观棋者/老弈），比「知道不说」多留一层涌现空间 | 类比（写作美学方法论） | 2026-08-13 |
| 环境叙事 Environmental Storytelling（Don Carson，Gamasutra 2000，出身迪士尼幻想工程） | 场景是「事情发生过的现场」：布景即证词，玩家从物证的因果痕迹自行重建故事；叙事预算从过场动画移到空间与道具摆放。方法论强化：「What Happened Here?」（Worch & Smith，GDC 2010）——把玩家变成主动侦读物证的参与者，自己拼出的故事比被动听到的记得牢 | 类比（实战方法论） | 2026-08-13 |
